# ЛР13 — Каталог мобільних телефонів із JSON

Продовження ЛР10 для варіанта 7 «Мобільні телефони». П’ять початкових телефонів збережено з ЛР10; шоста позиція — iPhone 15 із пам’яттю 256 ГБ.

## Відповідність завданню

| Вимога | Реалізація |
| --- | --- |
| JSON із заголовком і щонайменше шістьма товарами | `products.json`: `title` і масив `products` із шістьма телефонами |
| Запит на отримання JSON | `readJson()` і `fetchCatalog()` у `shop.js` |
| Картки генеруються через JavaScript | `renderCatalog()` створює всі елементи через DOM API |
| У HTML лише обгортка карток | Порожній `div#products` у `index.html` |
| Заголовок із JSON | `applyTranslations()` бере назву каталогу з `catalog.title` |
| Функціонал кошика з ЛР10 | Вибір кількості, підтвердження додавання, лічильник найменувань, окрема сторінка кошика, зміна кількості, видалення, суми й посилання оплати |

Кошик зберігається у localStorage. Повторне додавання того самого товару збільшує його кількість, а не створює другий рядок. Ціна та назва беруться з актуального каталогу, а не зі збереженого кошика. Різні варіанти пам’яті є окремими товарними позиціями.

Помилка мережі, відсутній файл, некоректний JSON або структура даних показують повідомлення з повторним завантаженням. Запит обмежено 15 секундами. Порожній каталог відображається окремим повідомленням. Кількість має бути цілим числом від 1 до 99; у кошику перераховуються суми рядків і загальна сума.

Посилання «Оплатити» відкриває підсумок навчального замовлення. Справжній платіж не виконується й не потрібний за завданням.

## Запуск і здавання

Завантажте всю папку `lab13` до свого GitHub-репозиторію, включно з `images` та `products.json`. При відкритті через GitHub Pages або Live Server заголовок і товари отримуються HTTP-запитом до `products.json` на тому самому сайті. Адреса відносна, тому працює і в підпапці репозиторію.

Публікація на GitHub Pages виконується власником репозиторію. Після публікації відкрийте сторінку `/lab13/` та перевірте у Network запит `products.json` зі статусом 200 і типом fetch.

Для відкриття подвійним кліком без локального сервера є `local-data.js`: він містить локальну копію тих самих даних. Вона використовується лише для `file://`; на GitHub Pages завжди виконується запит до JSON-файлу. Після зміни `products.json` локальну копію також потрібно оновити, якщо потрібен попередній перегляд подвійним кліком.

Supabase, облікові записи та серверна частина для цієї лабораторної не потрібні. Сховище кошика відокремлене від інших лабораторних.
