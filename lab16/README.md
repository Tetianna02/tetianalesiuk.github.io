# ЛР16 — запуск

Потрібен Node.js 22 або новіший.

У терміналі PowerShell:

```powershell
cd D:\JS-lab-works\lab16
npm.cmd install
npm.cmd start
```

Відкрити: http://127.0.0.1:3002/ або http://127.0.0.1:3002/users.

Для окремого HTTP-сервера в іншому терміналі з папки `lab16`: `npm.cmd run hello`. Адреса: http://127.0.0.1:3001/.

`npm.cmd install` потрібний лише перед першим запуском або після видалення `node_modules`. Зупинка сервера: Ctrl+C.
