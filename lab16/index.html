Серверний API на Node.js та Express

API повертає дані у форматі JSON. Для перевірки потрібно запустити сервер на своєму комп’ютері з установленим Node.js 22 або новішим.

cd D:\JS-lab-works\lab16
npm.cmd install
npm.cmd start

Після запуску відкрийте головний маршрут API або список користувачів.

Термінал залишайте відкритим. Зупинка сервера — Ctrl+C.
