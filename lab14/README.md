# Лабораторна робота 14

Продовження ЛР13: шість мобільних телефонів, динамічний каталог із JSON і кошик.

## Дві реалізації

- `index.html` — основна версія з i18next. Бібліотека завантажується через CDN `https://unpkg.com/i18next@21.6.16/dist/umd/i18next.min.js`.
- `native/index.html` — окрема реалізація на чистому JavaScript, без i18next. Файли перекладів завантажуються через fetch, тексти оновлюються через DOM.
- `cart.html` і `native/cart.html` — відповідні сторінки кошика.

Обидві версії використовують спільні `products.json`, `locales/uk.json`, `locales/en.json`, фотографії, стиль і логіку кошика з ЛР13. У HTML немає готових карток товарів. Українські дані телефонів, ціни та ідентифікатори збережено з ЛР13; додано англійські описи й одиниці пам’яті.

## Мови та кошик

Перший вхід відкриває обов’язковий вибір Українська / English перед показом каталогу. Мова зберігається у localStorage під ключем `lab14.language`. Наступні відвідування, обидві реалізації та сторінки кошика використовують збережену мову. Перемикач у шапці змінює мову без перезавантаження.

Перекладено каталог, описи телефонів, кошик, заголовок вкладки, модальні вікна, підказки, помилки, повідомлення й доступні назви елементів. Назви брендів і моделей залишені оригінальними. Грошові значення форматуються через Intl.NumberFormat відповідно до мови.

Кошик зберігається окремо від ЛР13 під ключем `lab14.phones.cart` і спільний для двох реалізацій. Лічильник показує кількість різних позицій. Додавання повторного товару збільшує його кількість; дозволені цілі значення від 1 до 99. Можна редагувати кількість, видаляти позиції, переглядати підсумок і відкривати навчальне підтвердження оплати.

## Запуск

Для перевірки fetch відкрийте папку через Live Server або GitHub Pages. У цьому режимі каталог і переклади завжди читаються з відповідних JSON-файлів; помилка запиту показує повідомлення та кнопку повторення.

Для запуску подвійним натисканням на HTML передбачений `local-data.js` із копією JSON. Він використовується тільки для `file://`, де браузери обмежують fetch локальних файлів. Після редагування JSON оновіть відповідні дані і в цьому файлі. Основна версія в локальному режимі або при недоступності CDN використовує незмінену копію i18next у `vendor`; файл ліцензії бібліотеки слід зберегти.

Для здачі завантажте всю папку `lab14` у власний репозиторій разом із підпапками. Основне посилання після публікації: `/lab14/`; реалізація на чистому JavaScript: `/lab14/native/`. Автоматична публікація не виконується.
